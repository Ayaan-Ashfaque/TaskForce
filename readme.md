# TaskForce

A simple desktop-based task management application built using Python and Tkinter.

TaskForce allows users to deploy their daily tasks, view them in an execution dashboard, and manually track their completion status through an interactive graphical interface.

## Features

* **Task Deployment:** Add tasks to your daily task list.
* **Task Deletion:** Remove tasks from the list.
* **Task Execution:** View all deployed tasks in a separate interface.
* **Completion Tracking:** Mark tasks as completed or pending using interactive buttons.
* **Visual Feedback:** Completed tasks are indicated in green, while pending tasks are indicated in red.
* **Navigation:** Switch between task deployment and task execution interfaces.
